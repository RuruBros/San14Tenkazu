# 천하도 (天下圖)

Steam 삼국지14 한국어판(SAN14CE_KO.exe)의 실행 중인 게임에 연결해
지도와 검색 목록에서 장수·도시·관문·부대 등을 편집합니다.

## 다운로드
[최신 포터블 ZIP 다운로드](https://github.com/RuruBros/San14Tenkazu/releases/latest)
Windows x64 포터블 ZIP과 SHA256 체크섬을 제공합니다.
ZIP에는 .NET 8 Windows Desktop Runtime이 포함되어 있어 별도 .NET 설치가 필요하지 않습니다.
게임 파일은 포함하지 않습니다.

## 실행 방법
1. ZIP을 새 폴더에 모두 압축 해제합니다.
2. San14Tenkazu 폴더의 San14Tenkazu.exe를 먼저 실행합니다.
3. 게임을 실행하고 세이브를 불러옵니다. 천하도가 게임 시작을 감지해 저장한 설정을 적용하고 자동으로 연결합니다.
   이미 실행 중인 게임에는 세이브를 불러오고 일시정지한 뒤 [게임 연결]로 연결합니다.
4. 지도나 목록에서 대상을 선택하고 값을 바꾼 뒤 [변경 적용]을 누릅니다.
   변경 내용을 남기려면 게임에서 저장합니다.

`게임 설정 → 개성·능력치`에서 9개성·능력치 200을 켠 경우 세이브를 불러오기 전에 천하도가 켜져 있어야 합니다.
천하도 없이 먼저 불러오면 게임이 능력치를 100으로 줄이고 6개 이상인 개성을 지웁니다.
그 뒤 천하도를 켜면 Steam 세이브 파일에서 불러온 세이브를 찾아 지워진 값을 되돌리며, 찾지 못하면 같은 세이브를 다시 불러옵니다.
줄어든 상태로 저장한 세이브는 복구할 수 없습니다.

편집기에서 개성을 모두 지운 변경은 같은 게임 실행·장수 상태에서 자동 복구가 덮어쓰지 않도록 유지합니다.

게임은 실행 중인 EXE 경로로 연결합니다. 게임을 종료한 상태에서는 Steam 설치 정보와
Library 목록을 검색하므로 다른 드라이브·폴더에 설치한 게임과 등록 신무장 파일도 찾습니다.
연결 전에 실제 플레이 상태를 검증합니다. 타이틀·로딩·상태 미확인 중에는 연결을 기다립니다.
타이틀로 돌아가면 이전 게임 데이터와 AUTO 조작을 비활성화하며, 미적용 입력이 있으면 자동 재연결을 보류합니다.

도시·이민족 분류, 도시명·거점 위치와 지도 지형은 현재 불러온 게임 데이터를 반영합니다.
추가 도시 47~51은 실제 데이터가 검증되는 편집 항목을 사용하며, 성채가 없는 항목의 성채 편집은 거부합니다.
추가 도시 47~51에는 날씨·재해 효과를 적용하지 않습니다. 확장 지도 패치의 전체 실게임 호환성 검증은 진행 중입니다.

## 주요 편집 기능
- 장수: 통솔·무력·지력·정치·매력, 충성·공적, 생몰년, 개성·전법·진형,
  주의·정책·관직, 배우자·의형제·친애·혐오, 소속·신분 변경(일반·재야·포로), 미등장 장수 등장·사망 장수 부활(일반·재야)
- 도시: 금·군량·병사·부상병·사기·내구·규모·태수
- 관문: 병사·사기·내구·기본 내구·태수
- 군: 인구·치안·상업·농업·병영 개발치
- 세력: 국호·작위·군사·색상, 친선·동맹 기간, 정책 배치, 군단별 군정 보유량
- 부대·시설: 병사·부상병·사기, 부상병 회복, 혼란·저지·도발 해제, 시설 내구
- 개성·명품: 개성의 조건·효과·수치, 명품 능력 보너스와 소유 장수
- 게임 밸런스: 진형의 기동·공격·방어·공성·파성, 전법·정책 효과,
  관직·작위 보너스, 주의 효과·비용. 변경 설정을 프로필로 저장하고 다시 적용합니다.
- 등록 신무장: 게임을 종료한 상태에서 이름·능력·개성·전법·진형·관계·열전 등 원본 편집
  저장 전에 원본을 백업하며, 변경은 다음 새 게임에 적용됩니다.
- 게임 설정 · 개성·능력치: 개성 9개 발동, 게임 무장 목록에 개성 9개 표시, 능력치 상한 200(100 성장·200 성장),
  성장 모드 변경 시 경험치 변환. 저장한 설정은 게임 시작·연결·새로고침 때 자동 적용합니다.
- 게임 설정 · 환경·재해: 사계절 지도 연출, 지역별 비·눈 그래픽, 비·눈 지역의 이동·사기 불이익,
  랜덤 재해(홍수·산불·가뭄·폭설·폭염)와 원본 알림·효과음, 감소율·발생 확률·피해량 입력. 저장한 설정은 일시정지 후 자동 적용합니다.
- 설정 가져오기: 다른 폴더·버전의 규칙 설정을 현재 게임의 기준값을 유지한 채 가져옵니다.
- 기타: 고대무장 해금, AI 설정 편집, AUTO(데모) 플레이 중지

## 사용 편의 기능
- 지도에서 도시·관문·부대 선택, 목록 검색·필터·정렬
- 지도 오른쪽 클릭으로 게임 카메라 이동
- 표의 열 머리글에서 검색·필터에 포함된 전체 항목을 일괄 수정
- 세력 목록에서 여러 군주를 선택해 일괄 항복시키기, 완료 건수·현재 처리 세력 표시
- 도시·관문·세력의 장수 표에서 충성 100·150 일괄 입력: 더 높은 값과 입력 중인 초안을 유지하고 변경 적용으로 반영
- 저장·변경 적용 버튼 옆에 작업 진행 상태 표시: 진행 중에도 툴바·지도 크기 유지
- 변경 기록과 되돌리기, 미적용 입력 유지

세력 목록의 `일괄 항복시키기`에서 항복을 받을 세력과 항복시킬 군주들을 선택합니다.
플레이어 세력과 항복을 받을 세력은 항복 대상에서 제외됩니다. 게임을 일시정지하고 다른 칸에 저장한 뒤 실행하세요.
도시·장수·부대가 함께 넘어가며 되돌릴 수 없습니다. 중간 실패 시 남은 항복은 중단하고 이미 처리된 항복은 유지합니다.

`소속` 탭의 `신분 변경`에서 일반·재야·포로를 선택합니다. 일반은 소속 세력과 거점을, 포로는 보유 세력을 지정합니다.
포로의 구금 세력은 현재 소속 세력도 선택할 수 있습니다. 선택한 세력의 군주 거점에 구금하며, 출진 중이거나 거점 밖에 있는 장수는 전환할 수 없습니다.
포로 전환은 게임의 포획 처리를 사용하므로 되돌릴 수 없으며 기존 되돌리기 기록도 지웁니다.

미등장·사망 장수는 목록의 `모두 (미등장·사망 포함)`에서 선택하고 `소속` 탭의 `장수 등장`·`장수 부활`을 사용합니다.
일반·재야 신분, 거점과 현재 연도보다 큰 몰년을 지정합니다. 미등장은 생년·등장년을 유지한 채 즉시 등장합니다.
사망으로 지워진 값은 자동 복원하지 않으며, 등장·부활은 되돌릴 수 없습니다.

## 설정과 업데이트
사용자 설정·규칙 프로필·백업·캐시는 %LOCALAPPDATA%\San14Tenkazu에 저장합니다.
하단 기록 패널의 내용은 같은 폴더의 logs\editor-날짜.log에 남으므로 재시작 뒤에도 자동 연결·적용 결과를 확인할 수 있습니다.
새 버전은 별도 폴더에 압축 해제한 뒤 기존 편집기의 미적용 입력을 처리하고 다시 실행합니다.

## 빌드와 패키징
Windows x64와 .NET 8 SDK가 필요합니다.
앱 빌드: dotnet build source\San14Tenkazu.csproj -c Release
로컬 개발자 배포: powershell -NoProfile -ExecutionPolicy Bypass -File .\source\Publish.ps1
개발자 메뉴 없는 공개용 포터블 ZIP 생성: powershell -NoProfile -ExecutionPolicy Bypass -File .\source\Package.ps1 -PublicRelease
로컬 개발자 빌드는 루트의 San14Tenkazu.exe에 개발자 메뉴를 포함합니다. 일반 빌드와 공개 패키지는 개발자 메뉴를 제외합니다.
결과는 dist 폴더의 ZIP과 .zip.sha256입니다.
패키징은 WPF·GPU·Native bundle 검사와 ZIP·Runtime 검증을 실행합니다.
