[InstallationAudit]
Title = 설치 파일 진단
Description = 설치된 Steam depot 명세와 디스크 파일을 읽어 비교합니다. 비교할 패키지마다 폴더를 하나씩 추가하세요. 패키지의 동일 내용과 동명 파일은 선택한 행의 근거에서 확인할 수 있습니다.
GameFolder = 게임 설치 폴더
PackageFolders = 패키지 폴더 추가
ClearPackages = 패키지 선택 해제
Packages = 패키지 파일
Coverage = 빌드 {build} · depot {read}/{total}
Scan = 검사 시작
Cancel = 중지
ChooseGame = 설치 폴더를 선택하세요
NoneSelected = 선택한 패키지 없음
Ready = 검사할 파일은 읽기 전용으로 엽니다.
Reading = 파일을 읽는 중
Cancelled = 검사를 중지했습니다.
ShowMatches = 원본과 일치하는 경로도 표시
Evidence = 선택한 행의 근거
Installed = 설치 파일
Result = 판정
File = 설치 상대 경로
DepotClaims = 경로를 포함한 depot
Content = 내용 대조
PackageFile = 패키지 내 파일
DiskMatch = SHA-256 일치 설치 경로
Runtime = DLL 옵션 활성 여부
Sources = 명세 및 판정 근거
Source = 출처
Matches = 원본 일치
Changed = 변경
Added = 명세 밖 추가
Missing = 누락
Unknown = 판정 불가
NoDiskFile = 확인한 설치 파일 목록에 경로가 없습니다.
DepotOverlap = 복수 depot 경로
ContentFound = 동일 내용 발견
NoMatch = 설치 파일에 동일 내용 없음
DiskNames = 이름이 같은 설치 경로
PackageNames = 다른 패키지의 동명 파일 (대상 경로 미확정)
PackageOverlap = 다른 패키지와 겹침
RelativeOverlap = 패키지 상대 경로 일치
NameOverlap = 파일 이름 일치
Unobserved = 미확인 (파일 검사)
DepotScope = 설치 depot 목록
ScopeDetail = 게임 폴더와 연결된 설치 명세를 기준으로 대조합니다. 패키지 표는 압축 해제된 패키지의 개별 파일과 설치 파일을 비교합니다. 설치 프로그램이 생성하거나 변환한 파일의 출처와 설치 순서, 실행 중 DLL의 로드 및 개별 옵션 활성 여부는 파일 지문만으로 판정할 수 없습니다.
ConflictingClaims = 같은 경로를 서로 다른 depot가 지정하며 디스크는 일부 후보와 일치합니다. 적용 우선순위는 이 명세에서 확인할 수 없습니다.
KnownMatch = 확인한 depot의 파일과 일치합니다. 전체 설치 명세는 불완전합니다.
Shared = 별도 소유 공유 depot
SharedUnresolved = 공유 depot 소유 앱의 설치 위치를 확인할 수 없어 게임 폴더와의 중복 여부가 미확정입니다.
Read = 명세 확인
InvalidManifest = Steam depot 명세 구조 또는 파일 경로가 올바르지 않습니다.
WrongInstallation = Steam 앱 식별자 또는 설치 폴더가 일치하는 앱 명세를 확인할 수 없습니다.
NoDepots = 앱 명세에 설치된 depot 목록이 없습니다.
InvalidPin = 설치된 depot 또는 manifest 식별자가 올바르지 않습니다.
MissingCache = 지정한 manifest가 로컬 캐시에 없습니다. 확인한 캐시 폴더
Encrypted = 명세 파일 이름이 암호화되어 경로 목록을 확인할 수 없습니다.
PinMismatch = 캐시 파일 내부의 depot 또는 manifest 식별자가 앱 명세와 다릅니다.
SteamState = Steam이 설치 완료 상태를 단독으로 보고하지 않았습니다.
InstallationChanged = 검사 중 Steam 설치 명세가 바뀌었거나 다시 읽을 수 없습니다. 설치 작업이 끝난 후 다시 검사하세요.
LinkSkipped = 링크 또는 재분석 지점의 내용은 검사 범위 밖입니다.
FileChanged = 읽는 동안 파일 크기가 바뀌었습니다.
OverlappingRoots = 각 패키지 폴더와 게임 폴더는 서로 포함되지 않는 위치에서 선택하세요.
UnreadablePath = 이 경로 또는 상위 폴더를 읽을 수 없습니다. 명세 및 판정 근거에서 해당 경로를 확인하세요.
IncompleteDepots = 일부 설치 명세를 확인할 수 없어 변경 또는 추가 여부를 확정할 수 없습니다.
NoContentHash = 명세에 유효한 파일 SHA-1이 없어 같은 크기의 내용을 판정할 수 없습니다.
IncompleteDisk = 일부 설치 파일의 지문을 읽을 수 없어 동일 내용의 존재 여부를 확정할 수 없습니다.
